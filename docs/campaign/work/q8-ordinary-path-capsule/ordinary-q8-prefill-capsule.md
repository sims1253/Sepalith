# RUN-09 ordinary Q8_0 path capsule

Status: **one bounded experiment nominated; not admitted and not run**. This capsule concerns the real non-integer ordinary Q8_0 path on the Renoir Vulkan device. It does not alter llama.cpp, build artifacts, model files, or runtime state.

## Finding

The captured runtime has `shaderIntegerDotProduct=true`, but both
`integerDotProduct8BitSignedAccelerated=false` and
`integerDotProduct4x8BitPackedSignedAccelerated=false`. The source resolves
`integer_dot_product` only when packed signed acceleration and shader support
are both present (`ggml-vulkan.cpp:7280-7282`), so the Q8_1 quantize-Y/MMQ
route is disabled. The ordinary path is therefore the relevant active path
for the Q8_0 model.

For contiguous F32 activations, `ggml_vk_mul_mat_q_f16`
(`ggml-vulkan.cpp:9190-9232`) leaves `quantize_y=false`, uses the ordinary
`ggml_vk_get_mul_mat_mat_pipeline` fallback, sets the effective activation
type to F32, and calls `ggml_vk_guess_matmul_pipeline`.

With `coopmat2` false, the selector at `ggml-vulkan.cpp:8757-8799` uses the
ordinary `mul_mat_{l,m,s}` availability flags. For `M > 64` and `N > 64`, it
returns the large pipeline when `mul_mat_l` is available; if large is
unavailable it falls through to medium. `aligned` selects the corresponding
`a_l` or `a_m` variant. The Q8_0 F32 shader family is generated by
`CREATE_MM2` (`4621-4623`, ordinary declaration at `4750`, f32 accumulator
variant at `5063`).

The single candidate is an opt-in **ordinary Q8_0 F32 large-to-medium
prefill choice** for short bounded prompt batches:

```text
if enabled
   && src0_type == Q8_0 && effective_src1_type == F32
   && !quantize_y && !qx_needs_dequant && !y_non_contig
   && !device.coopmat2                         // runtime gate, not an assumption
   && !device.integer_dot_product              // retain ordinary path
   && M in {2048, 6144} && K in {2048, 6144}
   && 128 <= N && N <= 256
   && ordinary large and medium variants are both available
   && baseline is (aligned ? a_l : l)
   && candidate is (aligned ? a_m : m)
   && K satisfies the candidate alignment
   && guess_split_k(baseline) == guess_split_k(candidate)
then use candidate
else use the existing selector result
```

The host branch belongs at the call-site after `aligned` is known and before
64-bit-index wrapping (`ggml-vulkan.cpp:9229-9236`). It must compare the
actual pipeline objects and recompute/compare `split_k`; it must not replace a
pipeline merely because its name contains `l` or `m`. If `mul_mat_l` is false,
the existing selector already chooses medium and this experiment is a no-op.
If either cooperative-matrix state is unknown or the availability/alignment/
split-K proof is missing, the branch must self-skip.

This is plausible because an integrated GPU may prefer the medium tile for
`N=128..256` even where a large tile is available, but there is no measurement
here establishing that. The candidate may self-skip on this device. No
cooperative-matrix, integer-dot, or fixed-CU assumption is used.

FFN=6144`. For one prompt ubatch (`batch=1`, `parallel=1`, `ubatch<=256`),

| gate/up projections | 6144 | 2048 | 128..256 |
| down projection | 2048 | 6144 | 128..256 |

`178, 117, 119, 163, 186, 85, 202, 89` at lines 222, 248, 267, 295,

## Required gates for a future arm

1. **G0 dispatch proof.** On the exact pinned binary/model and the existing
   accepted TRAIN fixture manifest, record for every candidate dispatch:
   `src0=Q8_0`, effective `src1=F32`, `quantize_y=false`, `qx_needs_dequant=false`,
   `coopmat2=false`, `integer_dot_product=false`, M/N/K, aligned state,
   baseline and candidate pipeline identities, availability flags, alignment,
   and equal split-K. A missing field or a failed predicate is a skip, never a
   guessed substitution.
2. **G1 correctness.** Run the same deterministic 8-prompt TRAIN panel on
   alternating baseline/candidate arms. Require identical generated token
   IDs, text hashes, terminal reason, cap status, and protocol result for all
   paired requests. Keep the panel and tokenizer bound by their existing
   manifests; no prompt text is copied into this capsule.
3. **G2 performance.** Separate first-use shader compilation from warm timing.
   Compare paired prompt-eval and end-to-end latency for the same N values,
   recording queue/wait time, allocation failures, and device errors. Retain
   the candidate only if its predefined median and p95 prompt-eval gate wins
   without a correctness or stability regression. A single fast request is
   insufficient and no quality claim follows from this gate.
4. **G3 fallback.** Confirm N outside 128..256, K/M outside the allow-list,
   unavailable aligned variants, unequal split-K, `coopmat2=true`, or any
   nonordinary activation path all use the unchanged selector. Confirm the
   64-bit-indexing wrapper is applied after either selection.

The bounded experiment is therefore **G0-pending / G1-pending / G2-pending**.
No build, server, benchmark, CUDA workload, or Opus launch was performed for
this task.
