# Pre-update gate candidate

Apply `pre-update-gate.patch` after the reviewed target-only patch. It adds `experiments/training/target_only_gate.py` and integrates the gate into `PinnedTrainBeginContract.on_train_begin`, after token/config restoration and before the first optimizer update. The earlier preparation files remain unchanged. Root must include the helper and patched trainer in the new immutable source identity.

The trainer captures a deep copy of the first16 admitted draw rows before SFTTrainer construction. At train_begin, the gate compares the actual post-Trainer rows with that copy, then uses the callback's actual prepared dataloader and the live trainer's `get_batch_samples` method. It checks four batch4 microbatches, exact token order, retained target/body/terminal fields, visible prompt attention, prompt/pad labels=-100, target+EOS supervision and the full accumulation denominator. It refuses alternate loss functions, label smoothing, denominator dropping, removed columns, worker prefetch, enabled dropout and nonempty optimizer state for fresh step0.

The gate forwards one actual microbatch through `trainer.compute_loss` without backward or an optimizer update. A temporary wrapper around the installed `unsloth.models.llama.unsloth_fused_ce_loss` symbol must witness exactly one actual call with unchanged labels, the correct four-microbatch denominator and causal shifting enabled. The fused output must use Unsloth's non-tensor empty-logits sentinel and a finite scalar loss. Merely receiving a finite model loss cannot pass the gate.

For an independent reference, the same model receives one unpadded row at a time with labels absent and `num_logits_to_keep=target_tokens+1`. Only suffix logits are retained; float32 cross entropy is accumulated in chunks32 over every target position, including EOS, and divided by the actual four-microbatch denominator. The last unused suffix logit is excluded. The allowed absolute difference is `max(0.005,0.01*abs(reference_loss))`, predeclared to accommodate bf16 batched versus unbatched rounding. No automatic tolerance widening or alternate loss fallback is permitted. Full-vocabulary suffix allocation and fused-kernel compilation still consume root's attempt budget; the existing supervisor remains the hard deadline.

The probe uses training-mode forward with no dropout, disables use_cache temporarily, and preserves the campaign RNG state, loader generators, original mode and cache settings. Parameter version counters and gradient identities must remain unchanged. It creates no optimizer update. The pass receipt includes batch identity SHA, actual denominator/call count, reference/fused losses, tolerance, timing and scope. Any error records failure and propagates out of train_begin. A missing pass receipt is not admission to the first update. If the loaded forward uses another fused entrypoint, ignores suffix-logit limits, or compiled dispatch bypasses the witness, the gate fails; root must review that concrete discrepancy.
