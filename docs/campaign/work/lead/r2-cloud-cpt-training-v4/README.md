# Full remaining-CPT cloud retry v4

This is a fresh, unadmitted, unarmed, unsubmitted retry packet. It preserves the reviewed v1 CPT lifecycle, the v3 phase evidence, and the immutable 34-file input revision. V4 resolves the supplied binding path before any child changes its working directory and passes the absolute path to all four consumers: sentinel, stager, checkpoint sidecar, and final uploader. The uploader now reports a sanitized path-bearing error and bounded source location.

Root reviews `launch-plan.json`, `payload-manifest.json`, tests, and every command in `root-commands.json`. Root must issue a fresh paid full-training admission, choose a fresh UUID32 and UTC deadline pair, and wait for the diagnostic node to be released. The admission must be copied to the exact stated path. Root then prepares the pre-arm binding, launches and verifies the independent watchdog, finalizes the binding, and submits exactly once. No action in this packet authorizes a provider allocation.

The remote full-training admission check explicitly rejects a diagnostic status. The managed bootstrap environment removes credential-like variables. Only the sentinel, private input stager, checkpoint sidecar, final uploader, and stdlib early-failure persistence receive the private token.
