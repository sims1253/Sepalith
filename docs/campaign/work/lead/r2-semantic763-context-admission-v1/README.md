# Semantic shard-5 context admission preparation

This packet applies the reviewed prediction-time full-document policy to all 763 semantic-supported rows in the frozen shard-5 ledger. Source, provenance, license, split, semantic closure, target occurrence, and candidate geometry are rechecked before reconstructing the complete pre-edit document. Prediction inputs are written separately and contain no target or gold fields. The copied TypeScript production selector and semantic provider render full-document and complete-span candidates from those inputs; the pinned tokenizer then applies `1 BOS + prompt + 1,024 reserve <= context` at 16K and 32K.

Analyzer support is not serving support. A row is held when its accepted closure relies on a symbol supplied only by the independently parsed package NAMESPACE, because the current editor provider cannot see that file. This accounts for 140 rows at both profiles. One additional row has invalid upstream candidate geometry. The 16K result contains 600 review-only token rows and 163 named holds; 32K contains 616 token rows and 147 holds. The candidates include 96 and 103 same-file-helper rows respectively. No complete target exceeds the 1,024-token reserve, and no target is truncated.

The actual complete-span provider supports 484/762 reconstructed rows. Across those rows, full-document prompts add a median 1,336 tokens (1.685x); the maximum is 88,443, which is why full documents are selected only after exact tokenization. The reconstructed set includes 94 Unicode and 199 CRLF documents; every emitted row retains the complete pre-edit hash, global replacement range, renderer order, exact post-edit reconstruction, and strict token protocol.

Within this 763-row cohort there are no duplicate prompt/target pairs and no prompt collisions with contradictory targets after selection. Deduplication against the existing 15,006 rows and other roxygen recovery pools remains a mandatory root union gate. These artifacts are review-only and do not admit training data or modify production.
