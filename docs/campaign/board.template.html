The lead owns the run schedule, checkpoint selection and final decision. Other agents can take a bounded task with its own files, inputs and acceptance criteria. Serving optimization can run beside training; final draft acceptance and latency are checked again on the selected weights.

  1. Start with the preparation tasks. Verify current jobs, storage and source revisions before using resources.
  2. Complete prerequisites before starting a dependent task. Keep optional branches outside the required delivery path.
  3. Hand back changed files, commands, validation results and an artifact receipt. The lead verifies the handoff before closing the task.
  4. Use the local campaign tracker and agent runbook to record owners and progress. This published view is a snapshot.
